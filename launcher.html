Support // FAQ

Questions?

Quick answers if something doesn't load or you're not sure where to start.

Which option should I try first?

Start with a normal tab, since it's the simplest and has nothing to set up. If the site is blocked, try about:blank, then the hosted HTML file, then the CodeHS class. Once you find the one that works, bookmark it.

The frame stays blank. What now?

A blank frame usually means your network is blocking thewebvault.org itself. Reload once to rule out a hiccup, then try a different option. If none of them load, the block may be affecting the whole site.

What is the Browser app?

It's a browser inside WebOS, built on Scramjet. Pages are fetched and rewritten through the Vault before being shown. Heavy sites with logins, video, or bot checks can be hit or miss.

Do I need to install anything?

No. The Vault is a website, so there's no download, extension, or setup. Open it in an up-to-date browser and it runs in the tab.

Can I use it fullscreen?

Yes. The Vault has a fullscreen option. Press Escape to leave fullscreen at any time.

How do I join the CodeHS class?

Choose "I only have CodeHS" above and press Join the class. Sign in or create an account, accept the invite, and open the Vault project.
