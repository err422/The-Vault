ACCESS METHOD 02

Open in about:blank

This opens a blank browser tab and loads The Web Vault inside it. The address bar will display about:blank.

If nothing opens, your browser may have blocked the pop-up. Allow pop-ups for this page and try again.

Download a small HTML file that opens The Web Vault in a fullscreen frame. You can host it somewhere or open it directly from your computer.

The launcher still needs to load thewebvault.org. If the site itself is blocked, this method won't bypass that restriction.

03 / SUPPORT

Questions?

A few things worth knowing before you enter.

Which option should I try first?

Start with a normal browser tab. If that doesn't work, try about:blank, then the HTML launcher, and finally the CodeHS option. Once you find something that works, bookmark it.

The frame stays blank. What now?

A blank frame can mean the network is blocking the site itself. Reload once to rule out a temporary issue, then try another access method. If none work, you may need to use a different network, such as your home Wi-Fi.

What is the Browser app?

The Browser app is a browser inside the WebOS, built on Scramjet. It routes web pages through the Vault before displaying them. Some sites with complex logins, video, or bot checks may not work correctly.

Do I need to install anything?

No. The Vault runs in your browser. You don't need to install an application or browser extension.

Can I use it fullscreen?

Yes. The Vault includes a fullscreen option. Press Escape to leave fullscreen mode.

How do I join the CodeHS class?

Select the CodeHS option above and open the invite. Sign in, accept the invitation, and open the Vault project from your class assignments.
